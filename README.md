# PerformingArtsCV — صحنه‌نما

پلتفرم رزومه و نمونه‌کار سینما و تئاتر. نام «صحنه‌نما» موقت است.

هر حساب یک صفحه شخصی دارد. ثبت‌نام تازه فقط با لینک دعوت فعال ممکن است؛ هر حساب لینک چندبارمصرف خود را در داشبورد می‌بیند. مشاهده رزومه و فایل دیگران فقط با اشتراک مشاهده معتبر ممکن است. فضای رایگان اولیه **۱۰۰ مگابایت** است و مدیر می‌تواند آن را برای همه حساب‌ها تغییر دهد. اشتراک فضا و اشتراک مشاهده مستقل‌اند.

## وضعیت فعلی

نسخه اولیه قابل اجرا شامل ثبت‌نام دعوتی و ورود، داشبورد دعوت‌ها، ویرایش رزومه، انتشار برای مشترکان، لینک آثار، آپلود خصوصی تصویر و ویدئو، جست‌وجو و منتخب‌ها، پنل مدیریت سهمیه، اشتراک و لینک‌های دعوت، اتصال اولیه پرداخت ریالی زرین‌پال و ابزار بکاپ و بررسی آن است.

پرداخت واقعی، استقرار عمومی و همگام‌سازی دو دستگاه هنوز عملیاتی نشده‌اند. قیمت پلن‌ها ساختگی وارد نشده است؛ مدیر آن‌ها را تعیین می‌کند. اتصال درگاه با پاسخ‌های شبیه‌سازی‌شده آزمایش شده و پیش از فروش واقعی باید در sandbox و سپس درگاه واقعی آزموده شود.

## اجرای محلی در ویندوز

Python 3.12 یا جدیدتر نصب باشد.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

سایت: [صفحه اصلی محلی](http://127.0.0.1:8000/)؛ مدیریت: [پنل مدیر محلی](http://127.0.0.1:8000/admin/).

در لینوکس همین دستورات با `.venv/bin/python` اجرا می‌شوند. حساب مدیر یا رمز پیش‌فرض وجود ندارد.

## تنظیمات مدیر

۱. در «تنظیمات سایت»، سهمیه رایگان را تعیین کن؛ مقدار پیش‌فرض ۱۰۰ است.
۲. در «پلن‌ها»، نوع اشتراک، مدت و قیمت ریالی را مشخص کن. برای پلن فضا، سهمیه **کل** را وارد کن.
۳. لینک دعوت مدیر را از داشبورد کپی و برای گروه اولیه بفرست؛ هر لینک برای چند حساب قابل استفاده است.
۴. در «لینک‌های دعوت» می‌توان لینک را غیرفعال کرد؛ «روابط دعوت» فقط برای بررسی است و قابل ویرایش یا حذف نیست.
۵. برای فعال‌سازی دستی، در «اشتراک‌های فعال‌شده» حساب، نوع، بازه اعتبار و مرجع فعال‌سازی را ثبت کن.
۶. صفحه پرداخت‌ها برای بررسی سابقه است و امکان اعلام دستی «پرداخت موفق» ندارد.

رزومه‌های پیش‌نویس حتی برای مشترکان قابل مشاهده نیستند. مدیر دارای مجوز می‌تواند محتوا را از پنل مدیریت بررسی کند؛ حساب مدیر نیز برای مرور عادی سایت به اشتراک مشاهده نیاز دارد.

## تنظیمات محیط

[نمونه تنظیمات](.env.example) فقط مرجع است؛ برنامه فایل `.env` را خودکار نمی‌خواند. متغیرها را در محیط اجرای سرور تنظیم کن. فایل، کلید، دیتابیس و بکاپ را وارد Git نکن.

نمونه تنظیم در PowerShell:

```powershell
$env:PUBLIC_BASE_URL = 'http://127.0.0.1:8000'
$env:ZARINPAL_SANDBOX = '1'
# ZARINPAL_MERCHANT_ID را در محیط محلی یا مدیریت اسرار سرور قرار بده.
```

تا وقتی کد پذیرندگی تنظیم نشده، پرداخت آنلاین غیرفعال است. [راهنمای پرداخت](docs/PAYMENTS.md) جزئیات را دارد.

## بررسی صحت

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe manage.py test
.\.venv\Scripts\python.exe scripts/concurrency_smoke.py
```

آزمون مرورگر اختیاری است و داده جدا از اطلاعات عادی برنامه می‌سازد:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe scripts/browser_smoke.py
```

این آزمون روی ویندوز از Edge نصب‌شده استفاده می‌کند؛ در سیستم‌های دیگر ابتدا `python -m playwright install chromium` لازم است.
