# وضعیت ورود فرانت و تحویل به بک‌اند

خروجی `feat-artistic-frontend.patch` شامل ۱۹ فایل، در شاخه `feat/artistic-frontend` روی نسخه اصلی پروژه اعمال شده است. ZIP و patch اصلی در پوشه محلی حفظ شده‌اند و وارد Git نمی‌شوند.

## تغییرات اصلاحی پس از ورود

- متن ثبت‌نام دیگر وعده ارسال SMS واقعی نمی‌دهد؛ سرویس هنوز متصل نیست.
- عدد ثابت جایگزین سهمیه تنظیم‌شده مدیر در متن ثبت‌نام حذف شد.
- سهمیه کل حساب در داشبورد دیگر به‌عنوان سهمیه رایگان همه کاربران معرفی نمی‌شود.
- پیام عبور از سهمیه با آزمون فعلی و رفتار واقعی برنامه هماهنگ شد؛ فایل قبلی حفظ می‌شود.
- راهنمای Copilot و تنظیمات اجرای VS Code اضافه شد.

## بررسی انجام‌شده

هر ۴۳ آزمون موجود سمت سرور گذشت؛ check و بررسی migration بدون مسئله بود و آزمون رقابت سهمیه نیز گذشت. تغییرات هنوز بازبینی کامل تصویری و مرورگری نشده‌اند. گزارش VALIDATION.md مربوط به نسخه قبل از این فرانت است و اثبات بررسی طرح جدید محسوب نمی‌شود.

## موارد باز برای Copilot

- لینک `/account/settings/` در قالب وجود دارد ولی route ندارد.
- قالب‌های تحصیلات، تجربه، تنظیمات حساب و OTP هنوز view و مدل لازم را ندارند؛ لینک به anchor ویرایش، جای CRUD واقعی نیست.
- OTP فعلاً ورودی‌های جدا، hidden code و شمارنده نمایشی دارد؛ کد JavaScript اتصال و ارسال/تأیید سمت سرور کامل نیست.
- وضعیت شماره و ایمیل واقعی و جریان تغییر آن‌ها پیاده نشده است.
- نمایش سال‌ها باید تقویم مشخص داشته باشد و داده قدیمی سوابق حفظ شود.
- عبارت‌ها و overlayهای محافظت یا واترمارک در UI جای حفاظت سرور یا جلوگیری از کپی را نمی‌گیرند.
- سناریوی browser_smoke باید با متن و انتخابگرهای طرح جدید تطبیق و دوباره اجرا شود.
- سند FRONTEND_BACKEND_CONTRACT دارای ادعاهای «متصل» است؛ هر ادعا باید با view و context واقعی سنجیده شود. مثلاً `free_storage_mb` و `free_mb` یک نام context نیستند و سهمیه کل با سهمیه رایگان تفاوت دارد.

مرجع ادامه کار: BACKEND_IMPLEMENTATION.md. این شاخه تا تکمیل بررسی، آماده انتشار عمومی اعلام نمی‌شود.
