## اعتبارسنجی

تمام داده‌ها ساختگی بودند. فرمان‌های Django با `DATA_ROOT` و `PRIVATE_MEDIA_ROOT` یکتای موقت اجرا شدند؛ آزمون‌ها و smokeهای دیگر نیز پایگاه‌داده و رسانهٔ موقت خود را ساختند و پاک کردند. هیچ DB، فایل رسانه یا حساب واقعی استفاده نشد.

مفسر آماده‌شده Python 3.14.7 با Django 5.2.19 و Playwright بررسی و استفاده شد. مرورگر Edge بدون رابط گرافیکی در viewport دسکتاپ ۱۴۴۰×۱۰۵۰ و موبایل ۳۹۰×۸۴۴ اجرا شد.

| فرمان/بررسی | نتیجهٔ واقعی | کد خروج |
|---|---|---:|
| `python manage.py check` | بدون خطای Django | ۰ |
| `python manage.py makemigrations --check --dry-run` | تغییر migration جاافتاده نبود | ۰ |
| `python manage.py test` | هر ۵۵ آزمون موفق | ۰ |
| `python scripts/invitation_concurrency_smoke.py` | دو ثبت‌نام هم‌زمان با یک دعوت، هرکدام دقیقاً یک حساب/رزومه/دعوت/لینک ساختند | ۰ |
| `python scripts/invitation_migration_smoke.py` | داده‌های ساختگی حساب، رزومه، اشتراک، منتخب و پرداخت حفظ شد؛ دعوت‌کنندهٔ تاریخی جعل نشد | ۰ |
| `python scripts/concurrency_smoke.py` | رقابت بارگذاری از سهمیه عبور نکرد و فایل اضافه باقی نماند | ۰ |
| `python scripts/browser_smoke.py` | موفق: دعوت، ورود/خروج، فرم رزومه، escaping، حریم خصوصی، انتشار/پیش‌نویس، فایل خصوصی، محدودیت/اشتراک، جست‌وجو/منتخب، موبایل، backup/restore | ۰ |
| `python -m py_compile portfolio\tests.py scripts\browser_smoke.py` | نحو آزمون‌ها و smoke معتبر | ۰ |
| `git diff --check` | خطای whitespace نداشت | ۰ |

سه smoke و Django check/migration drift در مسیرهای موقت اجرا شدند. پس از افزودن آزمون‌های مرحلهٔ ۳ و تغییر مرورگر، suite و browser smoke دوباره اجرا شدند و موفق ماندند. آزمون‌های زمانی بدون انتظار واقعی و با زمان کنترل‌شده هستند.
