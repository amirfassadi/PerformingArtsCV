# نقشه اجرا

## برنامه جاری — MVP آزمایش محدود دعوتی

از ۲۰۲۶-۱۱-۱۰، [تعریف مصوب MVP](MVP.md) و [چک‌لیست ۸ مرحله اجرا](MVP-TASKS.md) مبنای کار بعدی هستند. [تسک مادر #2](https://github.com/amirfassadi/PerformingArtsCV/issues/2) وضعیت اجرا را دنبال می‌کند. سیستم دعوت به محدوده اضافه شده و هنوز پیاده‌سازی نشده است.

بخش‌های زیر سابقه نسخه اولیه و کارهای انتشار/توسعه را حفظ می‌کنند. علامت‌های انجام‌شده مربوط به بررسی قبلی‌اند، نه پذیرش دوباره MVP دعوتی. مواردی مانند تبدیل ویدئو، بندانگشتی و ایمیل تأیید باید جداگانه اولویت‌بندی شوند و به‌صورت خودکار شرط پایان MVP مصوب نیستند.

## مرحله ۱ — پایه قابل اجرا

- [x] مستند محصول، مدل دسترسی و سهمیه.
- [x] ثبت‌نام، ورود و یک رزومه برای هر حساب.
- [x] ویرایش، پیش‌نویس و انتشار برای مشترکان.
- [x] لینک آثار، تصویر و ویدئوی خصوصی.
- [x] سهمیه رایگان ۱۰۰ MB با تنظیم مدیر.
- [x] سهمیه کل پلن فضا و کنترل مجموع مصرف.
- [x] اشتراک مشاهده مستقل و کنترل فایل مستقیم.
- [x] جست‌وجو، فیلتر شهر و منتخب‌ها.
- [x] مدیریت پلن، مدت، قیمت و فعال‌سازی دستی.
- [x] آداپتور درخواست و تأیید پرداخت ریالی زرین‌پال.
- [x] سفارش ثابت، تأیید تکرارپذیر و جداسازی مجوز آزمایشی.
- [x] فرمان بکاپ و بررسی سلامت snapshot.
- [x] آزمون خودکار قواعد اصلی و CI.

## مرحله ۲ — آماده‌سازی انتشار

- [ ] تعیین قیمت، مدت و ظرفیت واقعی پلن‌ها.
- [ ] نهایی کردن قواعد خرید پلن متفاوت و ارتقا.
- [ ] کد پذیرندگی، دامنه و آزمون واقعی sandbox.
- [ ] آزمون پرداخت واقعی کنترل‌شده و تطبیق رسید.
- [ ] تطبیق سفارش‌های بدون callback و مسیر پشتیبانی پرداخت.
- [ ] محدودیت تلاش ورود، ثبت‌نام، پرداخت و بارگذاری.
- [ ] ایمیل تأیید و بازیابی رمز، ارسال ایمیل واقعی.
- [ ] اعتبارسنجی کامل رسانه، اسکن، تبدیل ویدئو و تصاویر بندانگشتی.
- [ ] سیاست محتوای مجاز، گزارش محتوا، حذف حساب و نگهداری داده.
- [ ] آزمایش فشار، درخواست هم‌زمان و مصرف پهنای باند و دیسک.
- [ ] ابزار تشخیص فایل بدون رکورد یا فایل مفقود.
- [ ] استقرار HTTPS، سرویس خودراه‌انداز و مانیتورینگ.
- [ ] مشخص شدن سرور اصلی، دستگاه دوم، دیسک و اینترنت.
- [ ] انتقال امن و زمان‌بندی‌شده بکاپ به محل دوم و آزمون بازیابی کامل.
- [ ] مرور نهایی صفحه‌های فارسی روی موبایل و دسترس‌پذیری.

## مرحله ۳ — توسعه محصول

- [ ] PostgreSQL و معماری مناسب افزایش بار بر اساس اندازه‌گیری.
- [ ] فراخوان بازیگری و درخواست برای نقش.
- [ ] ارتباط داخلی و مدیریت پروژه‌های انتخاب بازیگر.
- [ ] احراز هویت حرفه‌ای و رزومه PDF.
- [ ] در صورت نیاز، جابه‌جایی خودکار سرویس هنگام خرابی سرور.

مرحله ۱ مبنای بررسی و توسعه است و معادل آماده بودن برای فروش عمومی نیست. موارد مرحله ۲ باید پیش از انتشار عمومی تعیین تکلیف شوند.
